# Enchanted Golden Foods Mod

## 📖 概要 (Overview)
Minecraftの世界には「エンチャントされた金のリンゴ（通称：ノッチリンゴ）」という強力なアイテムが存在しますが、**「なぜ他の『金の食べ物』にはエンチャント版が存在しないのだろう？」**という素朴な疑問からこのModは誕生しました。

本Modは、ただ回復力が高いだけのアイテムを追加するのではなく、**「探索」**や**「戦闘」**といった特定のシチュエーションに特化した最高峰のバフアイテムを追加します。冒険の準備を整え、エンチャントされた黄金の力で過酷なサバイバルを生き抜きましょう！

## ✨ 追加されるアイテム (Features)

本Modでは、バニラの「エンチャントされた金のリンゴ」と同等の価値を持つ2つの新しい食料を追加します。どちらも満腹時でも食べることが可能です。

### 🥕 エンチャントされた金のニンジン (Enchanted Golden Carrot)
**【探索特化型】** 洞窟探検や海底探索などの長期的なフィールドワークを強力にサポートします。
* **回復量**: 満腹度 6 / 隠し満腹度 14.4
* **付与効果 (5分間)**:
  * 👁️ 暗視 (Night Vision) レベル1
  * 🏃 移動速度上昇 (Speed) レベル2
  * 🫧 水中呼吸 (Water Breathing) レベル1

### 🍉 エンチャントされた金のスイカ (Enchanted Golden Melon Slice)
**【戦闘・機動力特化型】** ボス戦や対人戦、高低差の激しいバイオームでの立ち回りを劇的に向上させます。
* **回復量**: 満腹度 6 / 隠し満腹度 14.4
* **付与効果 (5分間)**:
  * ⚔️ 攻撃力上昇 (Strength) レベル2
  * 🦘 跳躍力上昇 (Jump Boost) レベル2
  * 🪂 低速落下 (Slow Falling) レベル1 （※落下ダメージも無効化）

## 🛠️ 入手方法 (How to Obtain)

これらのアイテムは非常に強力なため、入手にはそれ相応のコストや運が必要になります。

1. **クラフト (Crafting)**
   * 作業台の中央に「金のニンジン」または「きらめくスイカの薄切り」を配置し、周囲8マスを「金ブロック」で囲むことでクラフト可能です。（金インゴットではなく金ブロックが必要です）
2. **ルートチェスト (Loot Chests)**
   * バニラの「エンチャントされた金のリンゴ」と同じように、廃坑、ダンジョン、ネザー要塞、古代都市などの貴重な宝箱から非常に低い確率（1〜2%）で発見することができます。

## ⚙️ 動作環境 (Requirements)
* **Minecraft**: 1.20.1
* **Mod Loader**: Forge (47.4.0以降推奨)
* **Java**: 17

## 📝 導入方法 (Installation)
1. Minecraft 1.20.1対応のForgeをインストールします。
2. ダウンロードした本Modの `.jar` ファイルを、Minecraftの `mods` フォルダに配置します。
3. ゲームを起動して、アイテムが追加されていれば導入完了です。
