# 【仕様・要件定義書】Enchanted Golden Foods Mod

## 1. プロジェクト概要
マインクラフト内に、既存の「エンチャントされた金のリンゴ（ノッチリンゴ）」に匹敵する最上位食料アイテムとして、以下2つのアイテムを新規追加する。

1. **エンチャントされた金のニンジン（Enchanted Golden Carrot）**
2. **エンチャントされた金のスイカ（Enchanted Golden Melon Slice）**

## 2. 対象環境・動作前提
* **Minecraftバージョン**: 1.20.1
* **Mod Loader**: Forge（推奨バージョン: 47.4.0 系）
* **Javaバージョン**: Java 17

## 3. 追加アイテム詳細仕様

### 3.1. エンチャントされた金のニンジン
* **内部ID**: `enchanted_golden_carrot`
* **表示名**: エンチャントされた金のニンジン (ja_jp) / Enchanted Golden Carrot (en_us)
* **アイテム特性**:
  * **ビジュアル**: 常時エンチャントの光沢エフェクト（Glint）付与
  * **レアリティ**: `RARE` または `EPIC`（ツールチップ文字色：黄色/紫色）
  * **満腹度回復量**: 6（肉アイコン3個分）
  * **隠し満腹度（飽和度）**: 14.4（通常の金のニンジンと同等以上）
  * **特殊仕様**: 満腹時でも常に摂食可能
* **付与ステータス効果（持続時間: 各300秒 / 5分間）**:
  1. 暗視（Night Vision）Lv.1
  2. 移動速度上昇（Speed）Lv.2
  3. 水中呼吸（Water Breathing）Lv.1

### 3.2. エンチャントされた金のスイカ
* **内部ID**: `enchanted_golden_melon_slice`
* **表示名**: エンチャントされた金のスイカ (ja_jp) / Enchanted Golden Melon Slice (en_us)
* **アイテム特性**:
  * **ビジュアル**: 常時エンチャントの光沢エフェクト（Glint）付与
  * **レアリティ**: `RARE` または `EPIC`
  * **満腹度回復量**: 6（肉アイコン3個分）
  * **隠し満腹度（飽和度）**: 14.4
  * **特殊仕様**: 満腹時でも常に摂食可能
* **付与ステータス効果（持続時間: 各300秒 / 5分間）**:
  1. 攻撃力上昇（Strength）Lv.2
  2. 跳躍力上昇（Jump Boost）Lv.2
  3. 低速落下（Slow Falling）Lv.1
     * ※落下ダメージ無効化と跳躍補助の観点から「落下耐性」ではなく「低速落下」を採用。

## 4. アセット・リソース要件
* **テクスチャ**: 新規作成は行わず、バニラ既存のテクスチャを流用する。
  * ニンジン: `minecraft:item/golden_carrot`
  * スイカ: `minecraft:item/glistering_melon_slice`
* **描画仕様**: モデル定義JSONで上記テクスチャを指定し、コード側で光沢フラグ（isFoil / hasFoil）を有効化する。

## 5. 入手経路（ゲームバランス設計）

### 5.1. クラフトレシピ（作業台）
高コストな自作ルートとして実装。
* **金のニンジン**: 中央「金のニンジン」×1 ＋ 周囲「金ブロック」×8
* **金のスイカ**: 中央「きらめくスイカの薄切り」×1 ＋ 周囲「金ブロック」×8

### 5.2. ルートテーブル（自然生成チェスト）
バニラの「エンチャントされた金のリンゴ」と同等のドロップテーブルに相乗りさせる。
* **対象構造物**: 廃坑、ダンジョン、砂漠・ジャングルの寺院、ネザー要塞、砦の遺跡、古代都市、エンドシティなど、主要なトレジャールート（`chests/`配下）
* **出現確率・個数**: 1チェストにつき 1〜2% 程度の確率で 1個生成

## 6. 実装・コーディングにおける留意事項
1. **効果の動的更新（上書き）**:
   * 同系統のポーション効果が既にプレイヤーにかかっている場合、効果時間とレベルが本アイテムの仕様に合わせて適切に上書き・更新されるよう処理すること。
2. **ルートテーブルの追加方式**:
   * 競合回避のため、バニラのJSONファイルを直接上書きしないこと。
   * Forgeの「Global Loot Modifiers (GLM)」を用いたデータパック形式での動的注入を実装の前提とする。
